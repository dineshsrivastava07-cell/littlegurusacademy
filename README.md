# Little Gurus Academy

An EdTech online channel for preschool and tuition services.

## Overview

Little Gurus Academy is an educational platform designed to provide quality online learning experiences for preschool and tuition students. Our mission is to make education accessible, engaging, and effective for young learners.

## Features

- Interactive learning modules
- Student progress tracking
- Engaging educational content
- Online tuition support
- Preschool curriculum resources

## Technology Stack

- **JavaScript** (81.8%) - Frontend development and interactive features
- **Python** (16.4%) - Backend services and data processing
- **Other** (1.8%) - Supporting technologies

## Getting Started

### Prerequisites

- Node.js (for JavaScript components)
- Python 3.x (for backend services)

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/dineshsrivastava07-cell/littlegurusacademy.git
   cd littlegurusacademy
   ```

2. Install dependencies:
   ```bash
   npm install
   pip install -r requirements.txt
   ```

### Running the Application

Navigate to the frontend directory and start the development server:

```bash
cd frontend
npm start
```

The application will run on [http://localhost:3000](http://localhost:3000).
